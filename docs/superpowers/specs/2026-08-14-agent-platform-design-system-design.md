# AI Agent 平台设计系统

## 目标

为面向技术团队的 AI Agent 管理平台提供一组可复用的视觉令牌。界面以浅色、高信息密度的管理后台为核心，用深色侧栏建立导航边界，以蓝紫操作色和薄荷绿状态色建立科技感与可识别性。

## 选定方向：A · 电紫与薄荷

- 侧栏使用近黑蓝紫 `#171725`；它是导航承载面，不扩展到大面积工作区。
- 主操作色使用电紫 `#635BFF`；hover 与 active 仅改变明度，避免同一屏出现多个竞争性高饱和色。
- 薄荷 `#36D6B0` 只用于运行、成功、健康和数据已同步等正向状态；不用作主按钮色。
- 内容区使用雾白与浅冷灰；表格和表单以边框与字重区分层级，而非依赖重阴影。

## 色彩令牌

令牌按语义分层：基础色仅由令牌系统维护；组件只能消费语义令牌，禁止在页面组件内书写品牌色十六进制值。

| 类别 | 令牌 | 设计值 | 用途 |
| --- | --- | --- | --- |
| 主色 | `--color-primary-500` | `#635BFF` | 主按钮、聚焦、链接、当前导航 |
| 主色深态 | `--color-primary-600` | `#5248E8` | hover、按下态 |
| 主色弱化 | `--color-primary-50` | `#F1F0FF` | 选中底色、轻提示 |
| 辅色 | `--color-accent-500` | `#36D6B0` | 指标、运行状态、数据标记 |
| 成功 | `--color-success-600` | `#168B69` | 成功消息与健康状态文字 |
| 警告 | `--color-warning-600` | `#B86808` | 即将耗尽、需关注状态 |
| 危险 | `--color-danger-600` | `#C93D55` | 失败、删除、阻断性错误 |
| 画布 | `--color-bg-canvas` | `#F8F8FC` | 页面背景 |
| 次级底 | `--color-bg-subtle` | `#F1F1F6` | hover、禁用、分区底 |
| 表面 | `--color-bg-surface` | `#FFFFFF` | 卡片、表格、输入框 |
| 侧栏 | `--color-bg-sidebar` | `#171725` | 全局侧边栏 |

| 深色文本 | `--color-text-on-dark` | `#F4F4FA` | 侧栏主文字 |
| 深色弱文本 | `--color-text-on-dark-muted` | `#A9A9BC` | 侧栏次要文字 |

| 强边框 | `--color-border-strong` | `#D2D2DF` | 聚焦前边界、分隔线 |

## 形状、层级与动效

| 类别 | 令牌 | 值 | 使用边界 |
| --- | --- | --- | --- |
| 圆角 | `--radius-sm` | `6px` | 标签、复选框、小型控件 |
| 圆角 | `--radius-md` | `8px` | 输入框、按钮、菜单项 |
| 圆角 | `--radius-lg` | `12px` | 卡片、表格容器 |
| 圆角 | `--radius-xl` | `16px` | 抽屉、弹窗、重点面板 |
| 阴影 | `--shadow-sm` | `0 1px 2px rgba(23, 23, 37, .05)` | 静态卡片，仅作微层次 |
| 阴影 | `--shadow-md` | `0 8px 24px rgba(23, 23, 37, .10)` | 下拉菜单、浮层 |
| 阴影 | `--shadow-lg` | `0 20px 48px rgba(23, 23, 37, .16)` | 弹窗、抽屉 |
| 动效 | `--duration-fast` | `120ms` | hover、颜色和边框变化 |
| 动效 | `--duration-base` | `180ms` | 控件显示、菜单展开 |
| 动效 | `--duration-slow` | `240ms` | 对话框、抽屉入场 |
| 缓动 | `--ease-standard` | `cubic-bezier(.2, .8, .2, 1)` | 标准过渡 |

所有非必要动态效果在 `prefers-reduced-motion: reduce` 下归零。不得以动效承担信息传达；加载、成功、错误均须有文字与颜色之外的视觉语义。

## 组件映射

- **侧边栏**：深色表面；当前路由使用主色弱化的透明背景和亮色文字；hover 仅增加低透明度白色背景。
- **按钮**：主按钮使用主色 500 / 600；次按钮白底加边框；破坏性按钮用危险色，不得复用主色。
- **表格**：白色表面、浅边框、44px 行高；标题使用强文本，辅助字段用次文本；hover 行使用 `--color-bg-subtle`。
- **表单**：输入框为白底与默认边框；键盘 focus 使用主色描边及弱化主色外环；错误信息使用危险语义色。
- **状态**：健康/运行/成功使用成功与薄荷；警告和失败分别使用独立语义色，禁止将薄荷用于警告或删除。
- **对话页**：主工作区维持浅色；用户操作按钮用主色；连接、工具调用与完成状态使用薄荷和成功色。

## 可访问性

- 正文与画布、正文与表面均满足 WCAG AA 的 4.5:1 对比度目标。
- 交互控件最小可点击区域为 32 × 32px；表格行操作和主导航建议为 40px 以上。
- focus 样式始终可见，使用 `--color-primary-500` 和外环，不移除浏览器焦点提示而不提供替代。
- 文本、图标与色彩同时传递状态；仅色彩不能成为成功、失败、选中与禁用的唯一依据。

## 落地范围

本次仅修改 `agent-web/src/styles/index.css` 的全局令牌与基础覆盖，以及 `agent-web/src/App.vue` 的应用壳层以消费这些令牌。业务页面维持当前功能，不引入状态管理、组件库或业务逻辑。Element Plus 的主色与语义色变量将同步映射至该令牌系统。
