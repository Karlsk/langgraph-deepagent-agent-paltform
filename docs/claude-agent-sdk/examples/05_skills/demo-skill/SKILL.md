# Demo Skill

When the user asks for demo formatting, follow these steps:

1. Take the user's raw text as the only input.
2. Produce a card with two parts: a one-sentence summary, then exactly three bullet takeaways.
3. Reply in the same language as the input; do not add unrelated content.
