## 1. 安装

推荐 `uv`（本项目工具链一致）：

```bash
uv add deepagents
```

或使用 pip：

```bash
pip install deepagents
```

**可选 extras**（出处：`libs/deepagents/pyproject.toml` 的 `[project.optional-dependencies]`）：

| extra | 安装命令 | 引入的依赖 | 用途 |
|---|---|---|---|
| `[aws]` | `uv add "deepagents[aws]"` | `langchain-aws>=1.6.2,<2.0.0` | AWS Bedrock 模型与 Bedrock prompt caching |
| `[quickjs]` | `uv add "deepagents[quickjs]"` | `langchain-quickjs>=0.3.3` | QuickJS 沙箱执行能力 |
| `[video]` | `uv add "deepagents[video]"` | `av>=18.0.0,<19.0.0`、`pillow>=12.3.0,<13.0.0` | `read_file` 对视频内容的读取支持 |

## 3. 环境变量（provider API key）

deepagents 通过 `provider:model` 字符串解析模型（内部走 `langchain.chat_models.init_chat_model`），对应 provider 的 API key 需通过环境变量提供。示例为**占位符**：

```bash
export ANTHROPIC_API_KEY=sk-ant-...   # Anthropic 模型（默认示例所用）
export OPENAI_API_KEY=sk-...          # OpenAI 模型（如使用 openai: 前缀）
```

> ⚠️ **禁止将真实密钥写入代码、文档或提交到仓库**。本项目同样遵守该红线（见 AGENTS.md：密钥一律 env，禁止硬编码）。

## 4. 最小 quickstart

出处：`libs/deepagents/deepagents/graph.py::create_deep_agent`（签名与默认工具说明）。

```python
from deepagents import create_deep_agent

agent = create_deep_agent(
    model="anthropic:claude-sonnet-4-5",          # 必须显式传 model（见下方警告）
    tools=[],                                      # 与内置工具（ls/read_file/write_file/edit_file/glob/grep/execute/task）合并
    system_prompt="You are a concise research assistant.",
)

result = agent.invoke({"messages": [{"role": "user", "content": "用三句话介绍 LangGraph。"}]})
print(result["messages"][-1].content)
```

要点：

- **必须显式传 `model`**。`model=None`（回退默认模型）自 `0.5.3` 起弃用、将于 `1.0.0` 移除，且 `model` 参数类型将从 `BaseChatModel | str | None` 收紧为 `BaseChatModel | str`（出处：`graph.py` 中 `create_deep_agent` 的 docstring 与 `warn_deprecated` 调用）。
- `model` 接受 `provider:model` 字符串，也可直接传预初始化的 `BaseChatModel` 实例。
- 返回值是 LangGraph `CompiledStateGraph`，可直接 `invoke` / `ainvoke` / `stream`；已内置 `recursion_limit=9999` 与 `ls_integration: deepagents` metadata（出处：`graph.py` 末尾 `create_agent(...).with_config(...)`）。
- 默认 backend 为 `StateBackend()`（thread-scoped，文件存放在 graph state 中），无需额外配置即可跑通（出处：`graph.py` 中 `backend = backend if backend is not None else StateBackend()`）。

## 5. 与本项目集成的依赖冲突警告

**本项目 `pyproject.toml` 与 deepagents 0.7.5 存在版本抬升冲突，不能直接装进现有环境。**

| 依赖 | 本项目当前要求 | deepagents 0.7.5 要求 | 冲突 |
|---|---|---|---|
| `langchain` | `>=1.0.5` | `>=1.3.14,<2.0.0` | ⚠️ 需抬升 |
| `langchain-anthropic` | `>=1.0,<1.1` | `>=1.5.4,<2.0.0` | ⚠️ 区间无交集，必然冲突 |
| `langgraph` | `>=1.0.2` | 随 `langchain` 传递（更高版本） | ⚠️ 需随之抬升 |
| Python | 3.13 | `>=3.11` | ✅ 满足 |

**建议：在独立虚拟环境中验证示例**，不触碰本项目主依赖：

```bash
# 在仓库外或 .gitignore 覆盖的目录下创建隔离环境
mkdir -p /tmp/deepagents-poc && cd /tmp/deepagents-poc
uv venv --python 3.13
source .venv/bin/activate
uv pip install "deepagents==0.7.5"
export ANTHROPIC_API_KEY=sk-ant-...   # 占位符，勿提交
```

> 集成路径评估（抬升 LangChain 全家桶的回归风险 vs 独立服务隔离部署）留待 `09-高级用法与二次开发最佳实践.md` 展开。
